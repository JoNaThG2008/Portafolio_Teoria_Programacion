# 📖 1.1 Algoritmos

Un **algoritmo** es un conjunto ordenado, finito y definido de instrucciones que permiten resolver un problema o realizar una tarea específica. Constituye la base de cualquier programa informático, ya que describe de forma lógica los pasos que debe seguir una computadora para obtener un resultado.

Todo algoritmo trabaja con tres elementos fundamentales:

| Elemento | Descripción |
|:---------|-------------|
| **Entrada** | Datos que recibe el algoritmo para iniciar el proceso. |
| **Proceso** | Conjunto de operaciones realizadas sobre los datos. |
| **Salida** | Resultado obtenido después de ejecutar las instrucciones. |

### ✏️ Ejemplo

**Problema:** Calcular el área de un rectángulo.

**Entrada:** Base y altura.

**Proceso:** Área = Base × Altura.

**Salida:** Área del rectángulo.

# 📖 1.2 Pseudocódigo

El **pseudocódigo** es una representación intermedia entre el lenguaje natural y un lenguaje de programación. Permite describir la lógica de un algoritmo utilizando instrucciones sencillas y fáciles de comprender, sin preocuparse todavía por la sintaxis de un lenguaje específico.

Su principal objetivo es facilitar el diseño de programas antes de comenzar la programación.

### ✏️ Ejemplo

```text
Inicio

   Leer base
   Leer altura

   area ← base * altura

   Escribir area

Fin
```

# 📖 1.3 Diagramas de Flujo

Los **diagramas de flujo** representan gráficamente un algoritmo mediante símbolos estandarizados conectados por flechas que indican la secuencia de ejecución.

Esta herramienta facilita la comprensión de procesos, permite detectar errores antes de programar y mejora la comunicación entre los integrantes de un proyecto.

### Símbolos más utilizados

| Símbolo | Significado |
|:--------:|------------|
| 🟢 Óvalo | Inicio / Fin |
| ▭ Rectángulo | Proceso |
| ⬒ Paralelogramo | Entrada / Salida |
| ◇ Rombo | Decisión |
| ➜ Flecha | Dirección del flujo |

# 📖 1.4 Prueba de Escritorio

La **prueba de escritorio** consiste en ejecutar manualmente un algoritmo utilizando datos de prueba para verificar que la lógica implementada produce los resultados esperados antes de programarlo en la computadora.

Esta técnica ayuda a identificar errores y validar el funcionamiento del algoritmo.

---

# 📖 1.5 Lenguajes de Programación

Los **lenguajes de programación** permiten comunicarse con una computadora mediante instrucciones escritas siguiendo reglas sintácticas específicas.

Gracias a ellos es posible desarrollar programas, aplicaciones móviles, videojuegos, sistemas de información y páginas web.

Algunos ejemplos son:

| Lenguaje | Uso principal |
|:---------|---------------|
| C | Programación estructurada y sistemas. |
| Java | Aplicaciones multiplataforma. |
| Python | Inteligencia artificial, automatización y ciencia de datos. |
| JavaScript | Desarrollo web. |

---

# 📖 1.6 Programación por Bloques

La **programación por bloques** es una metodología visual donde las instrucciones se representan mediante bloques que se ensamblan como piezas de un rompecabezas.

Esta forma de programación facilita el aprendizaje de la lógica computacional al evitar errores de sintaxis y permitir concentrarse en el razonamiento del algoritmo.

Plataformas como **Scratch** o **Blockly** utilizan este enfoque para introducir a los estudiantes en el mundo de la programación.

# 💻 Desarrollo del ejercicio

## 📝 Planteamiento del problema

Un alumno necesita calcular el promedio final de sus tres notas.

Cada nota posee una ponderación diferente:

- Primera nota → **30%**
- Segunda nota → **30%**
- Tercera nota → **40%**

El objetivo es obtener el promedio final ponderado.

---

## 🔍 Análisis del problema

| Elemento | Descripción |
|----------|-------------|
| **Entrada** | nota1, nota2, nota3 |
| **Proceso** | promedio = (nota1 × 0.30) + (nota2 × 0.30) + (nota3 × 0.40) |
| **Salida** | Promedio final |

---

## 📐 Diseño del algoritmo

**Pseudocódigo**

```text
Inicio

   Leer nota1
   Leer nota2
   Leer nota3

   promedio ← (nota1 × 0.30) + (nota2 × 0.30) + (nota3 × 0.40)

   Escribir promedio

Fin
```

Durante el desarrollo de esta unidad surgieron diversas dificultades, especialmente al diferenciar conceptos como algoritmo, pseudocódigo y código fuente. Además, interpretar correctamente los problemas para identificar las entradas, procesos y salidas requirió práctica y análisis.
